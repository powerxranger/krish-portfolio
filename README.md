# Krish Aggarwal — Portfolio

Personal portfolio website built with React, TypeScript, and Vite.

## Tech Stack

- **React 19** + **TypeScript** + **Vite**
- **Tailwind CSS v4** for styling
- **Framer Motion** for animations
- **React Three Fiber** for the 3D hero backdrop
- **shadcn/ui** for base components
- **Lucide React** for icons

## Features

- 3D animated hero scene with quality-adaptive rendering
- Dark / Light / Fun theme switching
- Smooth scroll-linked animations and tilt cards
- Scramble text and typing effects
- Fully responsive

## Sections

1. Experience
2. Education
3. Projects
4. Technologies
5. Achievements
6. Contact

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
